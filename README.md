# ELC Pages

The public student site for the ELC. Practice tools, trainers and simulations —
no accounts, no tracking, works on a phone.

This repo holds only finished, cleared-for-public material — copied over from
the private `ELC` context-library repo once a resource is ready. It has no
connection back to that repo; nothing here updates automatically.

**Adding a new tool:** drop the self-contained `.html` file in `tools/`, add a
card for it in `index.html`.

**Live site:** enable in Settings → Pages → Deploy from a branch → `main` / `/(root)`.
